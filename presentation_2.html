3 AI 활용 성숙도 모델

"자율주행처럼, AI 개발에도 레벨이 있다"

성숙도 모델 개요

Level 이름 AI 범위 도구 예시 비유
L0 No AI 없음 - -
L1 Ad-hoc 코드 조각/함수 ChatGPT, 사내 챗봇 복붙 도우미
L2 Standardized 함수~모듈 + 문서 Copilot, JetBrains AI 코딩 어시스턴트
L3 Repo-aware 서비스(Repo) 단위 Cursor, Cline, Aider 페어 프로그래머
L4 Agentic Flow 멀티Repo + 실행 Claude Code, Devin 주니어 개발자
L5 Autonomous E2E 시스템 자율 파이프라인 자율 개발팀

Level 1: Ad-hoc (Personal Chat)

개인이 알아서 "챗"으로 도움받는 수준

적용 분야

  • 함수/로직 구현 보조
  • 코드 해석/리딩
  • 간단한 리팩토링 아이디어
  • 에러 원인 추정

판단 기준

  • 팀 표준/가드레일 없음
  • AI 산출물 재현/감사 어려움
  • "잘 쓰는 사람만 성과"

  • PR 템플릿에 AI 점검 항목

Level 3: Repo-aware (Mainstream)

"똑똑한 페어 프로그래머"

AI가 저장소 문맥을 읽고 Repo 단위 변경을 제안/생성

적용 분야

  • Repo 기반 코드 분석/수정 제안
  • 멀티파일 버그픽스/리팩토링
  • 테스트 보강/커버리지 개선

판단 기준

  • AI 제안이 PR 단위로 추적됨
  • 리뷰 가이드/규칙이 저장소에 존재
  • "담당자 승인 후 반영" 원칙

Level 4: Agentic Flow (AI First)

"주니어 개발자에게 태스크 위임"

업무 흐름의 기본 단위가 "에이전트 작업"

적용 분야

  • 이슈/티켓 기반 계획 수립
  • 코드/테스트 작성 + 실행 반복
  • PR 생성/릴리즈노트 초안

판단 기준

  • 목표/제약/검증/승인이 주 역할
  • 에이전트 실행 로그 남음
  • PR에 자동 요약 첨부

Level 5: Autonomous (AI Only)

정책 기반 AI 자율 수행 (미래 비전)

변경→검증→배포까지 자율 수행

적용 분야

  • Self-healing 패치
  • 자동 회귀 수정/성능 최적화
  • 보안 규칙 위반 자동 수정

판단 기준

  • 정책 기반 자동 승인 체계
  • 강력한 가드레일 필수
  • 저위험 영역부터 부분 적용

6 로드맵

단계별 추진 계획

단계별 타임라인

2025 Q2 - 파일럿 시작 L1→L2

선정팀 적용, 도구 검증

2025 Q3 - Level 2 확산 L2

팀 표준화, 가이드라인 배포

2025 H2 - Level 3 도입 L2→L3

Repo-aware 도구, 오픈소스 LLM 활용

2026 - Level 4 시범 L3→L4

Agentic 파일럿, 자동화 확대

단계별 상세

단계 대상 도구 성과 지표 산출물
파일럿 (Q2) 선정 2-3개 팀 Copilot, Cursor 사용성, 만족도 파일럿 보고서
확산 (Q3) 전체 개발팀 표준 도구 세트 PR 리뷰 시간 적용 가이드
고도화 (H2~) 핵심 프로젝트 Agent 도구 자동화율 운영 가이드

사업부 전략 연계

현재 바라보는 방향

  • 메인 개발은 사내에서 진행
  • 신규 모듈은 사외에서도 충분히 개발 가능
  • 개발 전체 분야에 AI 적용:
    기획 → 요구사항 → 설계 → 개발
